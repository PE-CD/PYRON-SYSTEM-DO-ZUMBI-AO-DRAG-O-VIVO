# Pixel Art Animation

Arquitetura do sistema de crianção e animação de pixel art utilizado como ferrmenta de desenvolvimento visual para o projeto Pyron System.

## Objetivo

Desenvolver uma ferramenta própria para criação, edição e animação de sprites em pixel art, permitindo o avanço do projeto Pyron System depois de meses e criação de futuramente de outros projetos de criação desse tipo.
